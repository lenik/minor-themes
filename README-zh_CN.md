# Minor Themes

一组 VS Code 配色主题，按三组组织：**Minor**（人物／气质外壳）、**Vibe**（影视、终端与氛围）、**Country**（各国传统文化色）。

## 主题说明

各主题色板位于 `scripts/`（从 worldman SOP themes 目录回吸同步），与 [UiTheme](https://github.com/lenik) 项目共用。浅色/深色成对主题为 **各自独立手写** 的 palette，并非由彼此推导。生成的主题 JSON 在 `themes/{minor,vibe,country}/`；扩展清单按同一分组顺序注册。

## Minor

柔和人物气质与身份外壳 — 粉彩、骄傲旗帜点缀、角色情绪。

### Innocent（纯真）

**含义：** Innocent（纯真）——纯净、柔和、不张扬。以腮红玫瑰与淡紫为语汇，柔而不淡、亲而不躁，避免高饱和喧哗。

**Innocent（浅色）** — 浅色：腮红玫瑰与柔薰衣草（色相约 280–340°）。近白底微粉洗，正文为淡紫灰。选中/焦点/主操作取雾玫瑰与长春花蓝，轻盈而不吵。装饰铬应弱于内容对比。

**Dark Innocent（深色）** — 深色：薰衣草暮光——柔紫暮色壳层（非中性灰）、丁香雾文字、雾玫瑰光标与长春花辉光。纯真在暗处化为静谧夜色，比 Dark Maiden 的墨色羊皮纸更冷、更柔。

### Maiden（少女）

**含义：** Maiden（少女）——年轻女性，亦含「少女气」的浪漫细腻。信笺般的温暖：柔软纸面配可读墨色。

**Light Maiden（浅色）** — 浅色：暖贝壳粉（低饱和红、高明度），正文深红玫瑰，高光金黄。橄榄绿弱标记带复古信笺感——面软、墨足、可读。

**Dark Maiden（深色）** — 深色：灯下墨与蜡——陈年羊皮纸棕影、五倍子玫瑰墨正文、蜜金高光、干鼠尾草绿弱色。文学、克制、前现代的女性气质。

### LGBTQ

**含义：** 取自吉尔伯特·贝克彩虹旗的色带作强调——欢庆，但不要把整界面刷成彩条。

**Light LGBTQ（浅色）** — 浅色：中性冷灰壳；彩虹色带作可读强调（红强调、橙/黄高光、绿串、蓝间隔、紫主操作、青辉光）。

**Dark LGBTQ（深色）** — 深色：雨夜游行——深风暴靛蓝壳托住彩带，如湿霓虹发光；欢庆需要暗作背景，而非把色彩闷死。

### Lesbian（女同）

**含义：** 内向的色彩语言——女女之爱的温热与亲近；温柔而非脆弱。

**Light Lesbian（浅色）** — 浅色：共处阳台的黄昏——暖桃壳、日落橙间隔、腮红粉辉、深玫品红关键字与光标；亲密而自信。

**Dark Lesbian（深色）** — 深色：日落后的体温——陶土棕影、余烬橙与腮红粉落在可可深度上；身体感、安静自信，有别于 Maiden 的文学玫瑰。

### Lady（淑女）

**含义：** Lady（淑女／时髦姐姐）——香槟腮红、口红珊瑚、兰花雾。亲密的晚间优雅——比 Gal 的沐阳甜辣更克制。

**Light Lady（浅色）** — 浅色：香槟腮红壳、口红珊瑚主操作、兰花间隔、金辉引用——精致亲昵。

**Dark Lady（深色）** — 深色：夜出光泽——酒暮壳、亮珊瑚口红色光标、兰花霓雾、香槟辉——自信的下班后暖调。

### Gal（甜辣）

**含义：** Gal（甜辣多巴胺）——充满精神的甜辣姐姐：鲜活草莓粉、奶油米白、蜂蜜辉光。高对比度、气色饱满的时尚底蕴，既有甜妹的糖度，又有姐姐的自信张扬。

**Light Gal（浅色）** — 浅色：奶油米白壳、爆裂草莓粉主操作、蜜糖杏色间隔、沐阳金引用——时尚、高对比的甜美，充满让人回头的高能辣妹精神。

**Dark Gal（深色）** — 深色：落日海滩的华丽——浓郁巧克力黑皮壳、晃眼的辣樱桃红光标、柔和珊瑚腮红迷雾、香槟辉光——极具元气、自信大方的时髦姐姐暖调。

### Tomboy（假小子）

**含义：** Tomboy（假小子）——运动休闲自信：丹宁蓝、卡其橄榄、工程橙强调。少粉；务实能量。

**Light Tomboy（浅色）** — 浅色：丹宁洗壳、靛蓝主操作、卡其草地间隔、安全橙引用——更衣室务实，非粉彩柔。

**Dark Tomboy（深色）** — 深色：夜训场地——石板丹宁壳、电靛蓝光标、橄榄草坪间隔、信号橙——暗处的运动感。

### Gym Bro（晨练）

**含义：** Gym Bro（晨光型男／清晨健身）——阳光自律的运动精神：蛋白纯白、清晨薄荷、日出杏橙。纯粹的晨练活力，干净、健硕、精神抖擞。

**Light Gym Bro（浅色）** — 浅色：蛋白纯白壳、活力薄荷绿主操作、破晓金间隔——清新的清晨空气与刚健身完的清爽感。

**Dark Gym Bro（深色）** — 深色：薄雾深蓝壳、晃眼的日出活力橙光标、花灰间隔——伴随第一缕晨光苏醒的、充满能量的健硕力量。

### Femboy

**含义：** Femboy——纯欲日常流：绝对领域白丝色系。核心：纯白、米色、浅灰；黑或浅粉点缀。宽松白大毛衣气质——慵懒、干净、带诱惑的干净氛围。

**Light Femboy（浅色）** — 浅色：近白／米色壳、柔炭黑正文、腮红粉主操作、雾灰间隔——大面积白丝感，粉与黑点缀克制。

**Dark Femboy（深色）** — 深色：夜房柔黑壳、象牙正文、腮红光标、冷灰间隔——同一白丝语汇的熄灯版；粉辉保持轻柔。

### Moe Girl（萌系）

**含义：** Moe Girl（萌系少女）——二次元萌感软萌：糖果粉、薄荷、天空蓝。比 Lady 时髦更圆润甜；比 Gal 沐阳甜辣更软。

**Light Moe Girl（浅色）** — 浅色：棉花糖粉壳、柔玫瑰正文、泡泡糖主操作、薄荷天空间隔、柠檬辉引用——卡哇伊粉彩，无霓虹。

**Dark Moe Girl（深色）** — 深色：暮光萌——藕紫夜壳、粉彩光标、薄荷辉间隔、柔柠檬星点——暗处仍保留可爱能量。

## Vibe

氛围主题 — 复古终端、影视引用、画室静谧、香氛与故事世界。

### MS-DOS

**含义：** Microsoft DOS——1980–90 年代经典 PC 文本模式。怀旧终端气质；并非为低视疲劳而设计。

**MS-DOS** — 高饱和 IBM 蓝底、白前景、黄字符串、绿操作、青弱文——熟悉的 DIR / AUTOEXEC.BAT 观感。仅深色。

### Matrix II（黑客帝国 II）

**含义：** 向《黑客帝国》（1999）致敬——近黑底上的霓虹绿；赛博终端，宜暗室。

**Matrix II** — 霓虹绿（约 h135°）落在偏绿近黑面板上。网格/边框微绿；光标与激活态发光。仅深色。

### X-Files（X 档案）

**含义：** 《X 档案》——联邦地下室卷宗、荧光官僚与夜林。日间机构纸色；夜间森林 CRT。

**Light X-Files（浅色）** — 浅色：胡佛大楼——马尼拉文件夹奶油壳、机构灰绿正文、森林绿光标、琥珀荧光笔引用；灯管下的案卷。

**Dark X-Files（深色）** — 深色：地下室与松林——森林夜绿黑壳、CRT 磷光淡文、异绿光标、手电琥珀辉、机密红强调。

### Only Yesterday（岁月的童话）

**含义：** 《回忆点点滴滴》（1991）——吉卜力笔下山形乡愁：红花、稻金、田野绿。

**Light Only Yesterday（浅色）** — 浅色：日光中的夏日记忆——日晒奶油壳、暖棕正文、红花强调、草地青绿间隔、稻田金高光；怀旧、轻柔、晒旧。

**Dark Only Yesterday（深色）** — 深色：黄昏榻榻米——赭色记忆影、褪奶油正文、红花灯笼红、金色回想与暮草地绿；日落后的温记忆。

### Morandi（莫兰迪）

**含义：** 得名于乔治·莫兰迪——粉尘般、低饱和、和谐的灰调。画廊般安静的绘画气质；饱和度刻意压低。

**Light Morandi（浅色）** — 浅色：暖灰米色窗壳、蓝灰正文。强调为降饱和青绿与雾玫瑰——无霓虹。边框柔和；对比克制但须可读。

**Dark Morandi（深色）** — 深色：打烊画室——赭棕影、粉笔灰冷色正文、雾青与褪鼠尾草绿强调——北窗低光里的颜料低语。

### Aroma（香氛）

**含义：** Aroma（香氛）——植物练习的暖陶土与奶油色语言（Ibvjahst Botanica）：陶土油瓶、亚麻日光、夜香树脂。柔和、落地、以香为先。

**Light Aroma（浅色）** — 浅色：晨间药铺——暖奶油壳、近墨赭正文、陶土赤陶操作色、焦糖辉光、鼠尾草绿间隔；绝非紫霓虹。

**Dark Aroma（深色）** — 深色：夜香扩香——树脂赭影、亚麻奶油字、焦糖光标与强调、鼠尾草低语间隔；同一种陶土暖意收进低光。

### Liaozhai（聊斋）

**含义：** 聊斋——宣纸、朱砂印、狐火翠玉、月下墨色；志怪与古典文言的夜色。

**Light Liaozhai（浅色）** — 浅色：宣纸奶油壳、墨黑正文、朱砂印主操作、翠玉间隔、灯笼金辉——白日里的古典志怪。

**Dark Liaozhai（深色）** — 深色：月下墨洗——近黑靛蓝夜、狐火翠光标、朱砂血强调、淡纸正文——子夜书斋里的志怪。

### Game of Thrones（权力的游戏）

**含义：** 权力的游戏——日间维斯特洛羊皮纸与铁灰；夜间守夜人冰蓝、兰尼斯特绯红与金。

**Light Game of Thrones（浅色）** — 浅色：御前会议羊皮纸壳、铁灰正文、兰尼斯特绯红主操作、史塔克冰蓝间隔、纹章金辉。

**Dark Game of Thrones（深色）** — 深色：守夜人黑壳、冰蓝 CRT 正文、血绯红光标、兰尼斯特金辉——凛冬将至的铬。

## 安装

**从扩展市场** — 在 VS Code 或 Cursor 中搜索 [Minor Themes](https://marketplace.visualstudio.com/) 并安装。

**从源码**

```bash
git clone https://github.com/lenik/minor-themes.git
cd minor-themes
pnpm install
pnpm run package
```

通过 **扩展 → … → 从 VSIX 安装…** 安装生成的 `.vsix`。

## 使用

1. 打开命令面板（`Ctrl+Shift+P` / `Cmd+Shift+P`）。
2. 运行 **首选项: 颜色主题**。
3. 在 **Minor Themes** 列表中选择主题。

## 开发

```bash
pnpm install
pnpm run sync       # 从 worldman SOP themes 回吸最新色板
pnpm run generate   # 重新生成 themes/*.json
pnpm run package    # 打包 .vsix（prepublish 会先 generate）
```
